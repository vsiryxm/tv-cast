# 开场台词示例（放到 U 盘根目录，文件名必须是 karaoke_openings.txt）
#
# 作用：播歌时在歌词左边浮出一张半透明白卡，写着这首歌的台词，给唱歌的人照着念。
# 没有开关：这个文件在就显示，删掉就一句都不显示。播歌时按遥控器 # 键可临时收起。
#
# 格式：
#   ## 歌文件名        —— 不带 .mp3 / .lrc，和 U 盘里的歌一模一样（只写纯歌名也认）
#   下面几行是台词     —— 一行一段，慢慢念
#   # 开头是注释
#
# 每首三四句、七八十个字，念下来差不多二三十秒。改词不用重装 App，
# 存好插回电视、重启 App 就生效。

## 月亮代表我的心 - 邓丽君
月亮挂在天上，不管人在哪儿，抬头看的都是同一个。
心里那点真心话，平时说不出口，就借这首歌说出来。
愿听到的人，都明白这份心。

## 02-故乡情 - 程琳
故乡的山还是那座山，故乡的水还是那道水。
人走多远，梦里回去的路都没变过。
这首歌一唱，回不去的小时候就回来了。
