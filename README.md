# tv-cast

把手机上的直播画面投到老电视，把直播间文字放大成满屏看板；另外附送一个**完全离线的电视端 K 歌机**。

## 简介

| 想做什么 | 一条命令 | 电脑要常开 | 需要 AI |
| --- | --- | --- | --- |
| 电视全屏看直播 | `./cast.sh apk` | 不用 | 不用 |
| 只放大直播下方那一横条文字 | `./cast.sh danmu` | 不用 | 不用 |
| 文字重排成超大字看板、消息累积 | `./cast.sh wall` | 要（macOS） | 本地 OCR |
| 离线 K 歌：U 盘存歌 + 全屏大字歌词 | `./cast.sh karaoke` | 不用 | 不用 |

前两档不碰 AI：文字本来就画在画面里，接收端把那一横条像素裁出来铺满即可，实时、零依赖。
第三档用 macOS 自带的 Vision 把像素翻成文字，再重排去重，字号最大、消息不会一闪而过。
K 歌走的是另一条路：不联网，电视自己读 U 盘里的 MP3 + LRC，自己画 1920×1080 歌词。

仓库里两个 Android 应用，都只有自家 APK、无第三方库：

- `receiver/` —— 电视端接收端：裸扫 MJPEG 帧（FFD8/FFD9）自绘上屏，不依赖浏览器、DLNA 或电脑
- `karaoke/` —— 电视端 K 歌机（`com.xinmin.karaoke`）：单实例 MediaPlayer 播放，Canvas 画歌词

## 环境说明

- **电视**：实测海信 LED50EC280JD，**Android 4.0.4 / API 15**，系统里没有 Miracast 接收端；
  已开 ADB 网络调试（本机是 5555）。其他 4.x 老电视同理，键码与 U 盘挂载路径可能不同。
- **手机**：实测红米 Note 10 Pro，装 ScreenStream（F-Droid 原版，MJPEG 推到 8080）。
- **网络**：电视、手机、电脑同一 WiFi；手机建议在路由器里设成静态 IP。
- **电脑（只用 macOS 验证过）**：`adb`（`brew install --cask android-platform-tools`）；
  只有 `wall` 档还需要 Xcode（提供 `swiftc` / Vision）和装了 `pillow` 的 `/opt/homebrew/bin/python3`。
- **K 歌**：只需要电视 + U 盘（FAT32），装完电脑手机都能关机。做伴奏才需要 ffmpeg + Demucs。
- 跑起来之后只有两台设备：手机 → WiFi → 电视，电脑不转发、可以关机。

## 安装步骤

### 1. 取代码、填三个 IP

```bash
git clone git@github.com:vsiryxm/tv-cast.git
cd tv-cast
cp config.env.example config.env
```

编辑 `config.env`，只写 IP，不带端口、不带 `http://`：

```
TV_IP=192.168.1.98        # 电视
PHONE_IP=192.168.1.83     # 手机
MAC_IP=192.168.1.100      # 电脑（仅扫码装机 / AI 看板用得到）
```

`config.env` 含家里真实 IP，不进仓库，clone 后必须自己 `cp` 一份。

### 2. 手机装发送端

装 `ScreenStream.apk`；懒得传文件就跑 `./cast.sh serve`，电视会显示二维码，手机扫码直装。
打开后选 **Local (MJPEG)** → 关掉 PIN → **Start** → 系统弹窗点允许。
它给出的 `http://手机IP:8080` 就是上一步填的 `PHONE_IP`，不用抄。

### 3. 电视装接收端（只做一次）

```bash
./cast.sh install     # 装仓库里现成的 tvcast.apk，不需要任何编译工具链
./cast.sh check       # 显示「8080 推流：已就绪」再往下
./cast.sh apk         # 电视全屏显示直播画面
./cast.sh danmu       # 改成只放大直播下方文字
./cast.sh wall        # AI 大字看板，前台常驻，Ctrl+C 会自动切回 danmu
```

### 4. K 歌机（可选，与上面互不影响）

U 盘里一首歌就是**同目录、同名**的三个文件：

```
月亮代表我的心.mp3        原唱
月亮代表我的心.lrc        歌词（UTF-8 / GBK 自动识别，可无）
月亮代表我的心.伴奏.mp3    伴奏（可选；缺了这首歌就只有原唱）
```

```bash
./cast.sh song "我的歌单/月亮代表我的心.mp3"    # 生成 .伴奏.mp3（本地分离，不上传）
./cast.sh song --tv "我的歌单/月亮代表我的心.mp3"  # 生成后直接推到电视 U 盘
./cast.sh karaoke                             # 装好 APK 并切到 K 歌台
```

遥控器：`1` 原唱 ↔ 伴奏（静音键 / `M` 同效）、`2` 重唱（整首从头）、`3` 或菜单键开 / 收歌单、
`0` 切歌、`OK` / 空格 播放暂停、`←/→` 双击快退快进 10 秒、`#` 显示 / 收起台词、
返回键连按两次退出。歌单里 `↑↓` 选歌、`OK` 马上唱、`0` 直接切歌。
没插 U 盘时画面停在启动页提示「请插入 U 盘」，插好自动重扫开始。

**曲库顺序**：U 盘根目录 `karaoke_setlist.txt` 里列过的排最前，其余按「点歌次数降序 → 文件名升序」。
点歌次数记在电视本机，完整唱完才 +1，只在重新扫描曲库时重排。

**配置**：`karaoke.conf` 有两处，优先级 **U 盘根目录 > APK 内置默认 > 代码默认**：

| 键 | 作用 | 默认 |
| --- | --- | --- |
| `app_name` | 台名（启动页、顶栏、欢迎语） | `K歌台` |
| `welcome` | 顶部跑马灯欢迎语 | `欢迎来到 <台名>，` |
| `opening_secs` | 台词卡最多停留秒数 | `30` |
| `opening_hold` | `1` = 开唱后也不提前收，停满秒数 | `0` |
| `live_start` / `live_end` | 直播开始 / 结束时间，严格 `HH:mm` | `18:30` / `20:00` |

构建期默认值写在 `karaoke/karaoke.conf`（**不入库**，先 `cp karaoke/karaoke.conf.example karaoke/karaoke.conf`），
`build.sh` 会把白名单里的 `app_name` / `welcome` / `opening_secs` / `live_start` / `live_end`
打进 APK 的 `assets/karaoke.conf`，改完要重新编译；`opening_hold` 只在 U 盘 conf 里生效。
日常改台名、欢迎语、台词、歌单、直播时间，只改 U 盘根目录那几个文本文件，**插回电视自动生效，不用重装 APK**。

**开场台词**（可选）：U 盘根目录放一个 `karaoke_openings.txt`，播歌时歌词左侧就浮出一张半透明白卡，
写着这首歌的台词，念完自动淡出。**没有开关——文件在就有，删掉就一句都不显示。**
文件按歌名分节，格式：

```
## 02-故乡情 - 程琳
故乡的山还是那座山，故乡的水还是那道水。
人走多远，梦里回去的路都没变过。
```

`##` 后面是歌文件名（不带 `.mp3` / `.lrc`，只写纯歌名也成），下面一行一段，
`#` 开头是注释；仓库里有示例 `karaoke/karaoke_openings.example.txt`，拷到 U 盘根目录改名即可。
每首最多停 30 秒（`opening_secs` 可调），默认开唱 2 秒后收；想让整段词念完，
在 `karaoke.conf` 写 `opening_hold=1`，台词卡就会停满秒数、不因开唱提前收。
播歌时按遥控器 `#` 键可以临时收起台词，再按一次恢复。

**今晚歌单**（可选）：U 盘根目录放一个 `karaoke_setlist.txt`，一行一首，就是今晚的演唱顺序：

```
# 井号开头是注释
02-故乡情 - 程琳
月亮代表我的心 - 邓丽君
```

列过的歌排在最前，其余仍按点歌次数排；写错或曲库里没有的歌名会被**忽略**，不是错误。
歌名带不带 `02-` 这类序号都认。删掉这个文件就回到纯点歌次数排序。

**直播提醒**（可选）：在 `karaoke.conf` 里写两个严格 `HH:mm` 的时间（24 小时制，
两位小时 + 半角冒号 + 两位分钟）：

```
live_start=18:30
live_end=20:00
```

两个都写对、且结束晚于开始才启用：进入直播时段（中途开机也会补一次）在**屏幕右侧中部**
弹出「直播开始啦」，结束前 10 分钟换成「还有 N 分钟」预告；两类提醒每天各一次，
**换一首歌时自动收起**（重唱、切原唱/伴奏不算换歌）。缺任一键、`18:5` / `25:00` /
全角冒号、结束早于开始，都判定为格式不正确 → 整个功能不触发，也不影响唱歌。
默认 18:30–20:00 写在构建期 `karaoke/karaoke.conf`（会打进 APK），U 盘根目录的同名文件可覆盖。
提醒按**电视本机时间**判断（`Calendar` 取设备时区），不是手机时间：实测这台海信时区是 **UTC**，
`adb shell date` 比北京时间慢 8 小时。要么把电视时区 / 时钟调准，要么在 U 盘 conf 里按电视
显示的钟点填（北京时间 18:30–20:00 对应 UTC `10:30` / `12:00`）。不支持跨夜时段。

## 注意事项

- **「准备就绪 / 等待手机推流」是正常准备态**，说明手机没点 Start；`./cast.sh check` 确认。
- **有黑边**：遥控器左右键切显示模式（0 模糊填充 / 1 裁切 / 2 拉伸 / 3 原始比例 / 4 弹幕文字）。
  竖屏内容投 16:9，不可能同时做到不变形、不裁切又铺满。
- **adb 连不上**：`adb kill-server && adb start-server`，并确认电视没待机；这台老系统常要重连一次。
- **电视只有音频输出，没有可用麦克风输入**（`AudioRecord` 能初始化，但读出来全是 0，是恒静音死通道）。
  人声继续走原来的无线麦链路；伴奏进耳机走「电视 3.5mm → 蓝牙 TX → 耳机」。
  电视 USB 口只供电、不是 USB 声卡，别买插 USB 出声的发射器。
- **3.5mm 插入会物理切断内置喇叭**，且与喇叭共用同一 PCM，电视音量别调到 0（会把发射器一起静音）。
- **K 歌「未找到歌曲」**：U 盘插回电视会自动重扫；停在启动页时按菜单键可手动重扫。
  U 盘要 FAT32，MP3 与 LRC 必须同名同目录；屏幕「曲库:」后面会显示实际扫到的目录。
  注意：U 盘插在电脑上时电视 `/mnt/sdcard` 是空的，日志里「扫描到 0 首歌」属正常。
- **伴奏只认 `歌名.伴奏.mp3`**；写成 `-伴奏` / `_伴奏` / `(伴奏)` 一律不识别。要让伴奏与原唱**等长**。
- **点歌次数（完整唱完才 +1）只在下次扫描曲库时重排**：重开 App / 插回 U 盘 / 启动页按菜单键重扫。
- **千万别开两个 MediaPlayer**：这台海信的播放器是 MTK 私有独占会话，第二个会把第一个顶成
  `PLAY_DONE`，触发自动切歌，变成每 2 秒无限重启。
